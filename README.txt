WEBSITE PORTOFOLIO NEON — HANAfi MAULANA
Cara pakai:
1. Ekstrak ZIP.
2. Simpan index.html, style.css, dan script.js di folder yang sama.
3. Buka index.html dengan Chrome/Edge/Firefox.
4. Edit teks, skill, dan proyek di index.html sesuai data kamu.
5. Ganti email contoh hanafi.maulana@example.com di HTML dan script.js dengan email kamu.
Fitur: responsive layout, dark/light mode, mobile menu, scroll reveal, filter portofolio, dialog detail proyek, formulir yang menyiapkan email.
Catatan: ilustrasi portrait dibuat dengan CSS, bukan foto orang asli. Form kontak memakai mailto dan tidak mengirim otomatis. Google Fonts memerlukan internet.
